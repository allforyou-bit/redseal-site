## 3. 수익화 구조 (확정안)

**4층 스택** — 품질(무료 퀴즈의 압도적 신뢰)이 전 층의 기반:

```
[4층] 광고 (AdSense) ── 도메인 이전 후 재신청. 보너스 취급. 10k pv/mo부터 유의미
[3층] 제휴 (Amazon 기존 + 도구·교재) ── 유지
[2층] 유료 제품 ── 트레이드별 문제은행 PDF/모의시험
       런칭가 CA$19~29 (경쟁 $79~107 대비 파괴적) → 정착 후 $39~49 + 취소선
       CTA 위치 = 퀴즈 결과 화면: "You scored 62% — pass mark is 70%. Get 250 more questions →"
[1층] 이메일 ── MailerLite 무료티어(자동화 포함) + 리드마그넷
       "무료 50문항 [트레이드] 모의시험 PDF" → 웰컴 5통 시퀀스 → 제품 피치
       시험날짜 수집("When's your exam?") → 카운트다운 시퀀스
```

**가격 사다리**: 무료 20문항 샘플 → $9~15 단일 트레이드 PDF(200문항+해설) → $24~39 풀번들(문제+공식+시험당일 가이드) → 추후 $49+ 멀티트레이드.
**판매 플랫폼**: v1 = **Ko-fi Shop** (이미 계정 있음, 5%수수료, 오늘 가능) → 월 CA$300+ 시 Payhip(임베드 우수) 또는 Gumroad(세금 MoR 완전 대행, 10%+50¢) 이전. ~~Lemon Squeezy~~(Stripe 인수 후 전환기, 회피).
**근거 수치**: 교육 니치 AdSense RPM $10~30이나 현 트래픽에선 무의미. 제품 전환 0.5~1.5% 기준 5k방문/월이면 $1,200~5,900/mo 그로스 가능. 이메일 리스트 가치 $0.10~0.50/구독자/월(초기).
