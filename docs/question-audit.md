## 5. 패턴 분석 (수정 우선순위 근거)
1. **전기 트레이드(309a·313a)에 미국 NEC 규정/수치가 캐나다 CEC로 둔갑한 사례 반복(확인 5건)** — 두 트레이드 전수 코드-수치 검증 권고
2. 정답 키 오류 표본 1건(0.4%) — 전수 환산 시 ~6건 추정, 정답-해설 모순 전수 검사 권고
3. 자동차 계열(310s·310t)에 실질 중복 4쌍 — 의미 기반 중복 검사 권고
4. 절차·적용형 부족 — 신규 출제 시 "상황+절차" 형식 우선
