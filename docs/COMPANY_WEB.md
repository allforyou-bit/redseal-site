## 1. 부서 편제 (6부서)

### W1 전략기획부 — 부서장: 총괄본부장 겸임
- 담당: $1,000 로드맵·게이트 판정, 가격 정책(런칭 CA$19 → 정착 CA$29~39 + 취소선), A/B 실험 설계
- 산출물: 게이트 판정문(월 1회), 가격 품의서
- 규칙: 모든 가격 변경은 사장 결재. 무료 퀴즈 축소 금지(§5 품질 원칙).

### W2 콘텐츠제작부 — 부서장: 콘텐츠 에이전트
- 담당: 신규 문항(절차·적용형 우선, MWA 미커버 영역), 기사 보강(얇은 페이지 → 실데이터 주입), 도구 페이지(시험비 조회·견습시간 계산기), **제품 PDF 제작**(리드마그넷 50문항 + 유료 풀뱅크)
- 규칙: 신규 문항은 공식 NOA/RSOS 출제비중 기준. 코드 인용은 반드시 캐나다 원문(CEC/B149/NPC) — 미국 NEC 혼입 금지. 트레이드명 치환식 양산 페이지 금지(2026 scaled-content 단속).

### W3 품질검수부(QC) — 부서장: QC 에이전트
- 담당: 문항 사실검증(감사 잔여: MED 9 + 확인필요 7 + 전기 2종 전수 코드검증), 배포 전 체크
- **배포 전 필수 체크리스트**: ① 수정 트레이드 `verify_quiz.py` ALL PASS ② JS 문자열 내 `<\/script>` 이스케이프 ③ 함수 재선언 금지(할당식만) ④ sitemap lastmod 갱신 ⑤ 신규 사실은 출처 URL 기록
- 규칙: 검증 불가 문항은 추측 수정 금지 — UNRESOLVED로 보류 목록 유지.

### W4 SEO·유통부 — 부서장: SEO 에이전트
- 담당: Search Console·sitemap·IndexNow, 도메인 이전 실무(canonical/OG/GA4 전면 교체), 배급 채널(YouTube 문제풀이 쇼츠·롱폼, Reddit 진성 참여), 내부링크 네트워크
- 규칙: 도메인 이전 시 github.io 자동 301 확인 + 신규 도메인 속성 등록 + sitemap 재제출을 한 커밋 안에서.

### W5 수익화부 — 부서장: 수익화 에이전트
- 담당: 상품 등록 자료(Ko-fi Shop → 성장 시 Payhip/Gumroad), 퀴즈 결과화면 CTA("You scored X% — pass mark is 70%"), 이메일 퍼널(MailerLite 웰컴 5통 + 시험날짜 카운트다운), AdSense 재신청 준비, 제휴 블록
- 규칙: CTA는 결과화면·이탈 직전에만(문제 풀이 중 방해 금지). CASL 준수(더블옵트인+주소+수신거부). 유료 델타 = 해설 심화·모의시험·인쇄용 포맷 (무료 문항 수 축소 금지).

### W6 데이터분석부 — 부서장: 분석 에이전트
- 담당: GA4·Search Console 주간 리포트(방문·전환·검색노출), 게이트 판정 데이터 공급, Telegram 보고
- 리듬: 주 1회 지표 스냅샷 → 월 1회 게이트 판정문.

## 5. 품질 원칙 (불변 — 사이트 품질 최고 유지)
1. 무료 퀴즈의 양·질을 줄여서 유료를 만들지 않는다. 유료 델타 = 해설 심화·시뮬레이션·인쇄 포맷.
2. 사실 정확성 > 물량. 검증 안 된 문항은 배포 금지.
3. 수정 배포 전 `verify_quiz.py` 필수.
4. 양산형 신호 제거 — 페이지마다 트레이드 고유 데이터(출제비중·임금·공구) 포함.
