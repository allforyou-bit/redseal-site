KAYMEDIA Internal Uploader — Privacy Policy

Effective date: August 28, 2026 · Contact: kay.kyeong.lee@gmail.com

The KAYMEDIA Internal Uploader is a private, internal command-line tool operated by a single individual (the owner of the KAYMEDIA YouTube channels). It is not a public product or service: it has no users other than the owner, no sign-up, no distribution, and no public interface. This policy describes how the tool uses YouTube API Services.

What the tool does

  • Uploads the owner's own finished videos to the owner's own YouTube channels on a schedule (videos.insert with publishAt).
  • Verifies that scheduled videos published correctly and updates their metadata (videos.list, videos.update, thumbnails.set).
  • Manages the owner's own playlists and channel sections (playlists.*, playlistItems.*, channelSections.*).
  • Reads and replies to comments on the owner's own videos (commentThreads.*, comments.*).
  • Reads the owner's own channel analytics (YouTube Analytics API) to guide content decisions.

Data access and storage

  • The tool accesses only channels owned by the authenticated account. It does not access, collect, or store any third-party user data.
  • Video metadata (titles, descriptions, IDs, publish times) and the owner's own analytics figures are stored locally on a single machine owned by the operator, solely for operating the channels. Nothing is sold, shared, or transferred to any third party.
  • OAuth 2.0 credentials are stored locally and used only to authenticate the owner's own account. Access can be revoked at any time at Google security settings.
  • Comment text written by viewers is read transiently to compose replies on the owner's own videos; it is not compiled, profiled, or retained beyond standard local logs.

Google / YouTube policies

This tool uses YouTube API Services and complies with the YouTube Terms of Service and the YouTube API Services Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Data deletion

All locally stored data can be deleted by the operator at any time by deleting the local files. To request deletion of anything related to this tool, contact kay.kyeong.lee@gmail.com.

Changes

Any change to this policy will be posted on this page with a new effective date.
